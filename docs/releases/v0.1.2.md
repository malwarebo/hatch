Maintenance release. No behavioral changes to the daemon, CLI, or sandbox
enforcement. This is the first **signed** release and adds a one-line
installer. See [v0.1.0](https://github.com/malwarebo/hatch/releases/tag/v0.1.0)
for the full feature list.

## Signed artifacts

Every artifact and the `SHA256SUMS` file is now signed with
[minisign](https://jedisct1.github.io/minisign/). Verify provenance with the
project's public key ([`hatch.pub`](https://github.com/malwarebo/hatch/blob/v0.1.2/hatch.pub)):

```bash
minisign -Vm SHA256SUMS -p hatch.pub
sha256sum -c SHA256SUMS --ignore-missing
```

## One-line installer

```bash
curl -fsSL https://raw.githubusercontent.com/malwarebo/hatch/main/install.sh | sh
```

The script detects your platform and architecture, downloads the matching
artifact, verifies the minisign signature (falling back to `SHA256SUMS` when
minisign or the key is unavailable), and installs the binaries. Set
`HATCH_INSTALL_DIR` to override the location (default `/usr/local/bin` as root,
`~/.local/bin` otherwise) and `HATCH_VERSION` to pin a version.

## Install

This release ships the following artifacts, each with a `.minisig` signature.
Verify against `SHA256SUMS` before installing.

- `hatch_0.1.2-1_amd64.deb`, `hatch_0.1.2-1_arm64.deb`
- `hatch-0.1.2-1.x86_64.rpm`, `hatch-0.1.2-1.aarch64.rpm`
- `hatch-0.1.2-x86_64-unknown-linux-gnu.tar.gz`,
  `hatch-0.1.2-aarch64-unknown-linux-gnu.tar.gz`
- `hatch-0.1.2-universal-apple-darwin.tar.gz` (signed/notarized `.pkg`
  when Apple credentials are supplied to the workflow)

See [`README.md`](https://github.com/malwarebo/hatch/blob/v0.1.2/README.md#install)
for the exact commands.

## Known limitations

Unchanged from v0.1.0:

- The Linux backend (namespaces + cgroups + iptables + Landlock + seccomp)
  has not yet been exercised end-to-end on a real host.
- No third-party security audit yet.
