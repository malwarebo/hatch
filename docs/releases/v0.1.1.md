Maintenance release. No behavioral changes to the daemon, CLI, or sandbox
enforcement; this release fixes the release pipeline, refreshes dependencies,
and improves the docs. See [v0.1.0](https://github.com/malwarebo/hatch/releases/tag/v0.1.0)
for the full feature list.

## Release pipeline

- Linux tarballs are now versioned (`hatch-0.1.1-x86_64-unknown-linux-gnu.tar.gz`),
  matching the macOS naming.
- A single aggregated `SHA256SUMS` file is attached to the release instead of
  one `.sha256` per asset. Verify with:

  ```bash
  sha256sum -c SHA256SUMS --ignore-missing
  ```

- Release notes are now sourced from `docs/releases/vX.Y.Z.md` in the
  repository, with GitHub's auto-generated changelog appended.
- The macOS unsigned tarball now ships with its own checksum.

## Dependencies

- `prometheus` 0.13 -> 0.14
- `sha2` 0.10 -> 0.11
- `getrandom` 0.3 -> 0.4
- fuzz lockfile: `hickory-proto` / `hickory-resolver` 0.24 -> 0.26
- GitHub Actions: `actions/upload-artifact` v4 -> v7,
  `actions/download-artifact` v4 -> v8, `softprops/action-gh-release` v2 -> v3
  (Node 24 runtimes; silences the Node 20 deprecation warnings in CI)

## Docs

- README now introduces the daemon model (`hatch-daemon` as a user-level
  systemd/launchd service, `hatch-shim` per-server bridge) and shows the
  per-process enforcement step in the architecture diagram.

## Install

This release ships the following artifacts. Verify against `SHA256SUMS`
before installing.

- `hatch_0.1.1-1_amd64.deb`, `hatch_0.1.1-1_arm64.deb`
- `hatch-0.1.1-1.x86_64.rpm`, `hatch-0.1.1-1.aarch64.rpm`
- `hatch-0.1.1-x86_64-unknown-linux-gnu.tar.gz`,
  `hatch-0.1.1-aarch64-unknown-linux-gnu.tar.gz`
- `hatch-0.1.1-universal-apple-darwin.tar.gz` (signed/notarized `.pkg`
  when Apple credentials are supplied to the workflow)

See [`README.md`](https://github.com/malwarebo/hatch/blob/v0.1.1/README.md#install)
for the exact commands.

## Known limitations

Unchanged from v0.1.0:

- The Linux backend (namespaces + cgroups + iptables + Landlock + seccomp)
  has not yet been exercised end-to-end on a real host.
- Release artifacts are not yet signed; `SHA256SUMS` proves integrity, not
  provenance. minisign / Sigstore signing is on the roadmap.
- No third-party security audit yet.
